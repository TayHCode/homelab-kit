# Contributing

Use invented examples and RFC 5737 addresses. Keep lab repos, secrets and private
terms outside this source repository. Run one test process at a time with Python
3.11 and 3.14, then ruff, mypy and build. Private-term tests use the external
HOMELAB_KIT_DENYLIST file. Changes must preserve manual execution, no uploads,
no model calls, generic host documentation and secret-location-only records.
