# How it works

The existing scaffold writes Markdown templates and a small TOML host inventory.
Each host uses the same generic template. Services are one Markdown file each.
The retained transport and runner bound raw collection in memory; the collector
stores accepted output as text, refusing whole captures on any secret-like hit.
REBUILD.md lists all machines; the root README.md remains yours to edit.
Your own agent edits the docs; homelab-kit makes no model calls or uploads.
